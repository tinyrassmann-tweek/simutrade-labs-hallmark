Run the complete app on your Mac

  1. Extract the complete build ZIP and open the simutrade-labs folder.
  2. Use Python 3.12 or later. No npm or pip installation is needed.
  3. Open Start-Mac.command, or run the command below from the folder.
  4. Visit http://localhost:3000. Open the Lab from the landing page.
python3 server.py

Guest records stay in the browser. Create an account to save on the server. The SQLite database is created at data/simutrade.db. Back up that file. Account and guest workspaces are separate; no automatic migration occurs.

Deploy to Google Cloud

Use an existing Google Cloud project and Google Cloud Shell. The script builds the included Dockerfile, creates dedicated build/runtime service accounts, enables required APIs, uses Firestore Native for durable records, and deploys the landing page and API together. Google supports source deployment using gcloud run deploy --source.

Your zero-spend rule

Local use requires no paid services. Google Cloud can incur charges and may require billing to be enabled. The script uses minimum zero and maximum one instance; this is not a spending cap. Review the project’s billing setup before executing it. Nothing has been purchased or provisioned by this delivery.

  1. Upload the ZIP to Cloud Shell and extract it.
  2. Open the extracted simutrade-labs directory.
  3. Run the command below, substituting your actual project ID and owner email. Use a suitable region.
  4. After a successful deployment, the script prints the service’s real HTTPS run.app URL. Open it and repeat the smoke checks below.
bash deploy-google-cloud.sh YOUR_PROJECT_ID us-central1 YOUR_OWNER_EMAIL

The deploying account needs permission to enable APIs, create/grant the shown service accounts, configure Firestore and Secret Manager, and deploy source. Existing project policies may require an administrator to grant access. The script preserves an existing Firestore Native default database and rejects Datastore mode.

Owner waitlist access

Register/sign in with the owner email supplied to deployment. The script creates a Secret Manager secret named simutrade-owner-token. Retrieve it privately from Google Cloud Console → Secret Manager and enter it in Contacts & pipeline → Owner access token. It is not saved in browser storage. Both the owner email and this token are required to read lead submissions.

Connect your own domain

The Cloud Run service URL is the interim address. To attach a domain, use a supported Google Cloud domain mapping or an HTTPS load balancer and the DNS records Google provides. Domain ownership, DNS access, region support, and possible load-balancer charges must be checked in the selected project. No domain was attached in this session.

Optional market data and AI

For licensed quotes, add TWELVE_DATA_API_KEY to the service through Secret Manager. Confirm your provider’s exact symbols, coverage, delay, and display rights. For AI drafts, add GEMINI_API_KEY through Secret Manager and set GEMINI_MODEL to a model available in that project. These optional services may be billable. Do not paste keys into HTML or client JavaScript.
