Privacy notice

What we store

The early-access form stores the name, email address, stated interest, consent version, and submission time. Account registration stores a name, email, salted password hash, and session records. Workspace records include simulated trades, reflections, contacts, drafts, and follow-up plans. Guest practice is kept in your browser.

How the data is used

Data supports early-access follow-up, account access, and the workspace features you choose. No automated marketing email is sent by this build. Do not enter private financial account numbers or sensitive family information. If Gemini is configured, the brief you submit to the cowork studio is sent to Google for generation. Market provider requests contain the selected symbol.

Storage and control

The local server uses SQLite. The Google Cloud package uses Firestore with a service account; browser clients have no direct database access. You can export workspace data and reset workspace content from Settings. Account deletion and access requests require an operator support channel, which must be added before a public launch. This build has no analytics or advertising trackers. Sessions expire after seven days; expired database records require periodic cleanup.

Operator launch step

Before accepting public registrations, add a monitored support address to this notice, set the retention policy, and connect email verification and password recovery. This notice describes the included implementation and is not a legal review.
